## 4. 生成時の注意点

### 品質確保

1. **プロンプトは英語で**: より高品質な結果
2. **詳細に記述**: 具体的であるほど良い
3. **アニメスタイル明記**: "anime-style", "anime illustration"
4. **レア度を強調**: "Legendary", "Epic" など

### 避けるべき要素

- 過度に露出の多い服装
- 暴力的な表現
- 宗教的に配慮が必要な要素
- 著作権のあるキャラクターに似すぎる

### 生成後の調整

1. **品質チェック**: レア度に見合う品質か
2. **キャラクター性**: 元ネタの特徴を表現できているか
3. **カードフレーム追加**: 別途編集ソフトで追加
4. **テキスト情報追加**: カード名、ステータス等

## 5. バッチ生成スクリプト（案）

### Python + Gemini API

```python
import google.generativeai as genai
import json

# プロンプトリスト読み込み
with open('card_prompts.json', 'r', encoding='utf-8') as f:
    prompts = json.load(f)

# Gemini API設定
genai.configure(api_key='YOUR_API_KEY')
model = genai.GenerativeModel('gemini-2.0-flash')

# 各カードを生成
for card in prompts['cards']:
    prompt = card['prompt']
    
    # 画像生成
    response = model.generate_images(
        prompt=prompt,
        number_of_images=1,
        aspect_ratio='3:4'
    )
    
    # 保存
    image = response.images[0]
    image.save(f"cards/{card['id']}_{card['rarity']}.png")
    
    print(f"Generated: {card['name']}")
```
