## 🎯 プロジェクトビジョン

**「日常のすべてを、冒険の資産に変える」**

現実世界の物体、場所、行動をゲーム内の資産（カード）に変換し、家族で協力しながら日常生活を攻略するRPGアプリ。AIが現実を解析し、動的にコンテンツを生成することで、無限の遊び方が可能になります。

## 🚀 次のステップ

1. **プロトタイプ開発** - n8n + LINE + Gemini APIで最小機能版を構築
2. **技術検証** - AI画像認識とカード生成のアルゴリズム検証
3. **地域パートナー獲得** - 協力店舗の募集と実証実験
